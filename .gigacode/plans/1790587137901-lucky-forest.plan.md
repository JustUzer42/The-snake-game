# План устранения ошибок автотестов в `the_snake.py`

## Анализ ошибок

Файл `the_snake.py` содержит **маркеры merge-конфликтов** (`<<<<<<< HEAD`, `=======`, `>>>>>>> 6af4b72...`), которые попали в файл при некорректном слиянии. Это основная причина большинства ошибок.

### Список ошибок из автотеста:

| Код | Описание | Причина |
|-----|----------|---------|
| F401 | `random.choice` / `random.randint` imported but unused | Автотест проверяет версию с `import random` вместо `from random import choice, randint` |
| D103 | Missing docstring in public function | Отсутствует docstring у функции |
| E800 | Found commented out code | Множество закомментированных блоков кода (маркеры конфликтов) |
| E116 | unexpected indentation (comment) | Неверная отступленность в закомментированных блоках |
| E501 | line too long (81 > 79 characters) | Строки длиннее 79 символов |

---

## Шаг 1: Очистка файла от маркеров merge-конфликтов

**Файл:** `the_snake.py`

Удалить все строки с маркерами:
- `<<<<<<< HEAD`
- `=======`
- `>>>>>>> 6af4b729c3bbd686a86361fa2aa3d7d18f944010`

**Стратегия выбора кода:** оставить версию HEAD (локальную), так как она содержит более подробные docstring'и и полную реализацию.

---

## Шаг 2: Исправление импортов

**Файл:** `the_snake.py`, строка 1

Заменить:
```python
from random import choice, randint
```

На:
```python
import random
```

И заменить все вызовы `choice(...)` → `random.choice(...)` и `randint(...)` → `random.randint(...)` по всему файлу.

---

## Шаг 3: Удаление закомментированного кода

**Файл:** `the_snake.py`

Удалить все закомментированные блоки кода (строки, начинающиеся с `#` и содержащие код), которые вызывают ошибки E800 и E116. Это строки в диапазоне ~46-106, содержащие закомментированные варианты кода из старой версии.

---

## Шаг 4: Исправление docstring'ов

**Файл:** `the_snake.py`

Добавить отсутствующие docstring'и для публичных функций (ошибка D103). Проверить все функции на наличие docstring.

---

## Шаг 5: Исправление длины строк

**Файл:** `the_snake.py`

Разбить строки длиннее 79 символов (ошибка E501) на несколько строк.

---

## Шаг 6: Проверка и отправка

1. Прогнать локально проверку кода (flake8/pycodestyle)
2. Запушить исправленный файл в репозиторий:
   ```
   git add the_snake.py
   git commit -m "Fix: remove merge conflicts and fix PEP8 errors"
   git push origin main
   ```
