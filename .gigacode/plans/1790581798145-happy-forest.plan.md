## 3. Что необходимо реализовать (из HTML-урока)

### 3.1 Класс `GameObject`
| Элемент | Тип | Описание |
|---------|-----|----------|
| `position` | атрибут | Позиция на поле, инициализируется центром экрана `((SCREEN_WIDTH//2), (SCREEN_HEIGHT//2))` |
| `body_color` | атрибут | Цвет объекта (RGB-кортеж), определяется в дочерних классах |
| `__init__(self, position=None, body_color=None)` | метод | Инициализация атрибутов |
| `draw(self, screen)` | метод | Абстрактный, `pass` по умолчанию |

### 3.2 Класс `Apple` (наследуется от `GameObject`)
| Элемент | Тип | Описание |
|---------|-----|----------|
| `body_color` | атрибут | `(255, 0, 0)` — красный |
| `position` | атрибут | Случайная позиция на поле |
| `__init__(self)` | метод | Задает цвет, вызывает `randomize_position()` |
| `randomize_position(self)` | метод | Случайная позиция: `randint(0, GRID_WIDTH-1)*GRID_SIZE, randint(0, GRID_HEIGHT-1)*GRID_SIZE` |
| `draw(self, screen)` | метод | Рисует красный квадрат с цветной границей `BORDER_COLOR` |

### 3.3 Класс `Snake` (наследуется от `GameObject`)
| Элемент | Тип | Описание |
|---------|-----|----------|
| `length` | атрибут | `1` — начальная длина |
| `positions` | атрибут | Список координат сегментов, начальная — центр экрана `[(center_x, center_y)]` |
| `direction` | атрибут | `(1, 0)` — вправо по умолчанию |
| `next_direction` | атрибут | `None` — следующее направление |
| `body_color` | атрибут | `(0, 255, 0)` — зелёный |
| `last` | атрибут | `None` — позиция последнего сегмента для стирания |
| `__init__(self)` | метод | Инициализация всех атрибутов |
| `update_direction(self)` | метод | Применяет `next_direction` к `direction`, сбрасывает `next_direction` в `None` |
| `move(self)` | метод | Вычисляет новую голову, `insert(0, new_head)`, если `len(positions) > length` — `pop()`. Обновляет `self.last` |
| `draw(self, screen)` | метод | Рисует все сегменты + голову, затирает `self.last` чёрным квадратом |
| `get_head_position(self)` | метод | Возвращает `self.positions[0]` |
| `reset(self)` | метод | `length=1`, `positions=[center]`, `direction=random.choice([UP, DOWN, LEFT, RIGHT])` |

### 3.4 Функция `handle_keys(game_object)`
- Перебирает `pygame.event.get()`
- `QUIT` → `pygame.quit()`, `raise SystemExit`
- `KEYDOWN` → проверяет стрелки, устанавливает `next_direction` (нельзя развернуться на 180°)

### 3.5 Функция `main()`
```
pygame.init()  # уже есть в прекоде вне main, но в main тоже может быть
    snake = Snake()
    apple = Apple()

    while True:
        clock.tick(SPEED)
        handle_keys(snake)
        snake.update_direction()
        snake.move()

        if snake.get_head_position() == apple.position:
            snake.length += 1
            apple.randomize_position()

        if snake.get_head_position() in snake.positions[1:]:
            snake.reset()

        screen.fill(BOARD_BACKGROUND_COLOR)
        apple.draw(screen)
        snake.draw(screen)
        pygame.display.update()
```

### 3.6 Требования
- Все классы и методы должны содержать docstrings
- Код должен соответствовать PEP 8

## 4. План реализации

### Шаг 1: Реализация класса `GameObject`
**Файл:** `the_snake.py`
- Заменить `...` на определение класса
- Атрибуты: `position`, `body_color`
- Методы: `__init__`, `draw`

### Шаг 2: Реализация класса `Apple`
- Наследование от `GameObject`
- `__init__`: `body_color = APPLE_COLOR`, `randomize_position()`
- `randomize_position()`: случайные координаты в пределах сетки
- `draw(screen)`: `pygame.Rect` с `APPLE_COLOR` и `BORDER_COLOR`

### Шаг 3: Реализация класса `Snake`
- Наследование от `GameObject`
- `__init__`: `length=1`, `positions=[center]`, `direction=RIGHT`, `next_direction=None`, `body_color=SNAKE_COLOR`, `last=None`
- `update_direction()`: применение `next_direction`
- `move()`: вычисление новой головы, insert/pop, обновление `last`
- `draw(screen)`: рисование всех сегментов + затирание `last`
- `get_head_position()`: возврат `positions[0]`
- `reset()`: сброс состояния

### Шаг 4: Реализация функции `handle_keys`
- Обработка `pygame.QUIT`
- Обработка стрелок с проверкой обратного направления

### Шаг 5: Реализация функции `main`
- Создание `Snake()` и `Apple()`
- Цикл `while True` с `clock.tick(SPEED)`
- Обработка ввода, движение, проверка столкновений
