# Краткое описание скачанных файлов

## Источник
Страница курса Яндекс Практикум: «Изгиб Питона» — проект «Змейка» (Python + Pygame).

## Содержимое `info/Змейка_files/` (~120 файлов)

### CSS-файлы (~70 файлов)
- Стили UI-компонентов Яндекс Практикума (prisma UI kit)
- Шрифты, кнопки, модалки, сайдбар, уведомления
- Не относятся к игре

### JS-файлы (~30 файлов)
- `editor.main.js`, `editor.main.css` — веб-редактор кода Monaco Editor
- `code.js` — логика редактора кода на странице
- `app-config.js`, `common-flow.js`, `fast-track.js` — конфигурация платформы
- `faq.js`, `faq-v2.js` — блок FAQ
- `glossary.ru.js`, `messages.default.proficiency.ru.js` — локализация
- `wizard.js`, `prof-window.js` — UI-виджеты платформы
- `exp.js`, `gtm.js`, `adsdk.js`, `tag.js` — Яндекс.Метрика, аналитика, реклама
- `loader.js`, `loader.min.js`, `implementation.min.js` — загрузка страницы
- `react-with-dom.min.js` — React для рендеринга контента
- `proficiency-B4CGmVv1.js` — основной JS бандл приложения Практикума

### Изображения
- `image_1734439342.png`, `image_1734439377.png`, `image_1734439399.png` — скриншоты из урока (игровое поле, змейка)

### HTML
- `Змейка.html` — сама страница урока (развёрнута)
- `pageView.html`, `practicum_ym_id.html`, `saved_resource.html` — вспомогательные страницы

## Вывод
Скачанные файлы — это **ресурсы веб-страницы Яндекс Практикума**, а не код игры.
Реальный код игры (прекод) содержится **внутри HTML-файла** как встроенные фрагменты и описания.
